# Bisseção e Newton-Raphson

Este é um projeto acadêmico desenvolvido por alunos da Universidade do Vale do Itajaí (UNIVALI) como parte da disciplina de **Cálculo Numérico**.

## 💡 Objetivo

O projeto tem como finalidade oferecer uma ferramenta web interativa para o cálculo de raízes de funções matemáticas utilizando os métodos numéricos de:

- 🔹 Bisseção  
- 🔹 Newton-Raphson

A aplicação visa fornecer uma abordagem prática e intuitiva para estudantes e interessados em métodos numéricos, permitindo a visualização e interação com os algoritmos diretamente pelo navegador.

## 📂 Estrutura do Projeto

- `bissecao.html` / `bissecao.js`: Interface e lógica do método da Bisseção  
- `newton_raphson.html` / `newton_raphson.js`: Interface e lógica do método de Newton-Raphson  
- `sobre.html` / `sobre.css`: Página com informações sobre o projeto  
- `index.css`: Estilização geral  

## 🚀 Como Executar

Não é necessário instalar nada. Basta:

1. Clonar ou baixar este repositório:
   ```bash
   git clone https://github.com/Bernardo-Escobar/Bissecao-NewtonRaphson.git
   
2. Abrir os arquivos bissecao.html ou newton_raphson.html no navegador de sua preferência.

Requisitos:
Qualquer navegador moderno (Chrome, Firefox, Edge, etc.).
Nenhuma dependência externa é necessária.
